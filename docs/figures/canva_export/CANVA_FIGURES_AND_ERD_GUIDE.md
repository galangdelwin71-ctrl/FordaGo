## Paalala sa Paggawa sa Canva (Napakahalaga!)
1. **Wag lalagyan ng Title Banner sa loob ng Canvas:**
   * Sa Word document, ang opisyal na caption ay nakalagay na sa **ibabaw** ng picture (hal. *Figure 2. Agile Methodology Framework*).
   * Kapag naglagay ka pa ng title sa loob ng Canva image, magiging "double-double" ang label sa papel. Diretso agad sa diagram graphics ang ilagay sa Canva!
2. **Font Style:**
   * Gumamit ng **Times New Roman** o malinis na Sans-serif tulad ng **Inter**, **Montserrat**, o **Segoe UI** para propesyonal at malinaw tingnan.
3. **Kulay (Color Palette):**
   * Background: Puti (`#FFFFFF`)
   * Primary Dark / Borders: Navy o Charcoal (`#0F172A`, `#1E293B`, `#000000`)
   * Accent Colors: Emerald Green (`#16A34A`), Sky Blue (`#0284C7`), Amber Gold (`#F59E0B`), Red Milestone (`#DC2626`).

  * Laravel Reverb WebSockets
  * 1-on-1 Coach-Client Chat

* `Laravel Eloquent ORM` ◄──────► `MySQL Database Queries (ACID)`

### Figure 9: Entity-Relationship Diagram (ERD)
* **Caption sa Papel:** `Figure 9. Entity-Relationship Diagram (ERD) of FordaGO`
* **Layout:** Relational Database tables na may Primary Keys `[PK]`, Foreign Keys `[FK]`, at connecting relationship lines (One-to-Many `1───<`).

Heto ang **100% kumpletong listahan ng bawat table at mga columns** para direktang makopya sa Canva table cards:

#### Table 1: `users` (Core User Accounts)
* `id` : INT `[PK]`
* `username` : VARCHAR(100)
* `first_name` : VARCHAR(100)
* `last_name` : VARCHAR(100)
* `email` : VARCHAR(150)
* `password` : VARCHAR(255)
* `role` : ENUM('admin','user','staff','coach')
* `phone` : VARCHAR(20)
* `gender` : ENUM('male','female','other')

* `membership_status` : ENUM('active','expired','pending')
* `weight_kg` : DECIMAL(5,2)
* `height_cm` : DECIMAL(5,2)
* `fitness_goal` : VARCHAR(100)
* `membership_expiry` : DATE
* `created_at` : TIMESTAMP

#### Table 2: `attendance` (Entrance Check-In Records)
* `id` : INT `[PK]`
* `user_id` : INT `[FK -> users.id]`
* `check_in_time` : DATETIME
* `membership_type` : ENUM('daily','monthly')
* `payment_status` : ENUM('paid','pending')
* `confirmed_by` : INT `[FK -> users.id]`
* `confirmed_at` : DATETIME
* `notes` : TEXT

#### Table 3: `equipment` (Gym Machinery & QR Labels)
* `id` : INT `[PK]`
* `name` : VARCHAR(150)
* `category` : VARCHAR(100)
* `muscle_group` : VARCHAR(100)
* `qr_code` : VARCHAR(100)
* `description` : TEXT
* `video_url` : VARCHAR(255)

#### Table 4: `equipment_scan_logs` (QR Scan Analytics)
* `id` : INT `[PK]`
* `user_id` : INT `[FK -> users.id]`
* `equipment_id` : INT `[FK -> equipment.id]`
* `scanned_at` : DATETIME

#### Table 5: `workout_sessions` (Daily Workout Logs)
* `id` : INT `[PK]`
* `user_id` : INT `[FK -> users.id]`

## Buod ng mahahalagang Katotohanan para sa Canva & Defense:
1. **Attendance Check-In:** Ang **member ang nag-i-scan** ng official counter QR code gamit ang kanilang mobile phone camera.
2. **Respondents:** Eksaktong **20 total**:
   * **5 IT Experts** (ISO 25010 evaluation)
   * **1 Gym Owner** (operational feasibility)
   * **1 Front-Desk Staff** (counter POS & attendance monitoring)
   * **13 Gym Members** (mobile app user experience)
3. **Gantt Chart:** Nagsimula noong **Enero 2026** at magtatapos sa Oral Defense sa **Oktubre 2026**.
4. **Wording:** Malinis, diretso, walang teknikal na "overclaims" (walang unverified milliseconds, walang automated phpunit tests claim, at walang redundant titles sa loob ng graphics).
