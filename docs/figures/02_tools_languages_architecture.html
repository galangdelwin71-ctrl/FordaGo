Technical Architectural Explanation:
FordaGO utilizes a modern, decoupled Tri-Tier System Architecture designed for scalability, zero hardware lock-in, and rapid response times. The Presentation Tier is engineered using Ionic 8 and Angular 18 to deliver a unified cross-platform mobile experience on Android devices as well as responsive desktop administration. The Application Tier is powered by Laravel 11, orchestrating role-based access control (RBAC), POS inventory logic, and QR token validation. A dedicated Real-Time WebSocket Tier (Laravel Reverb running on port 8080) handles instant bi-directional messaging and live turnstile check-in event broadcasts without polling overhead. Development and testing are accelerated using Google Antigravity as the advanced agentic AI pair programming IDE alongside Visual Studio Code, Docker, and Postman.
