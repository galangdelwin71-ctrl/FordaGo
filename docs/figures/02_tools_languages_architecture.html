Client-to-API Channel
HTTPS REST endpoints with Sanctum bearer authorization, input validation, and structured JSON responses.
Real-Time Duplex Channel
WebSocket protocol (Port 8080) broadcasting instant coach-client chat messages, typing events, and turnstile alerts.
Data Integrity Channel
Eloquent ORM managing transactional database operations, foreign key cascades, and daily automated cloud snapshots.
Full-Stack Architecture Overview: The Presentation Tier interfaces with the Application Tier via secure HTTPS REST APIs while maintaining continuous duplex WebSocket connectivity through Laravel Reverb. The Application Tier validates business rules, manages RBAC authorization, and executes ACID-compliant relational transactions across MySQL 8.0.
