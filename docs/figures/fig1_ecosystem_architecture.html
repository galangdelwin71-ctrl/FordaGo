FORDAGO: TRI-TIER ECOSYSTEM ARCHITECTURE

for AFFORDA Gym – Cabiao Branch

TIER 1: PRESENTATION

(Ionic 8 & Angular Mobile / Web)
•
Member Mobile Client & PWA Dynamic QR pass display, workout split logging, 1RM personal records, optical QR machine video guides, and supplement cart checkout.
•
Trainer Studio & Scheduling Suite Trainee client roster management, customized workout plan creation, coaching session calendar, and duplex consultation messaging.
•
Administrative Command & POS Walk-in registrations, POS counter cashiering, inventory stock replenishments, revenue audits, and vector PDF/Excel analytics exports.
•
Front-Desk Attendance & POS Station Front-desk dashboard monitoring live member QR check-ins, verifying counter cash payments, and managing walk-in registrations.
•
Capacitor Native Hardware Bridge Cross-platform camera stream access, biometric fingerprint/FaceID authentication, offline caching, and push notification services.

TIER 2: APPLICATION & LOGIC

(Laravel 11 REST API Services)
•
Sanctum Authentication & RBAC Stateful API bearer tokens, 5-tier role-based access middleware guards, TOTP 2FA engine, and encrypted credential handlers.
•
Real-Time Reverb WebSocket Gateway High-throughput Laravel Reverb server on Port 8080 delivering instant duplex chat broadcasting, live typing status, and administrative alerts.
•
Multi-Channel Payment Processing PayMongo payment gateway webhook verification for GCash, Maya, and card payments, alongside front-desk counter cash register tracking.
•
Attendance & Verification Controllers Encrypted dynamic QR token parsing, anti-passback security validation, entrance logging, and automated member pass renewal calculations.
•
Inventory & Vector Report Engine Automated low-stock threshold triggers, multi-table financial aggregations, DomPDF vector document rendering, and Excel spreadsheet exports.

TIER 3: DATA & STORAGE

(MySQL 8.0 & Cloud Asset Storage)
•
Relational Database Engine MySQL 8.0 relational database with InnoDB storage engine enforcing ACID transaction compliance, foreign keys, and cascade rules.
•
3NF Normalized Relational Schema Normalized schemas for users, memberships, attendances, equipment, workout_sessions, products, orders, and payment records.
•
Cloud Media & Tutorial Storage Secure cloud repository hosting high-definition equipment video tutorials, machine instruction placards, profile media, and receipts.
•
Immutable Audit Trails & Logs Persistent system activity logs recording administrative modifications, financial transactions, security events, and gym attendance access histories.
•
Automated Backup & Recovery Scheduled daily mysqldump database snapshots, transaction log retention, and disaster recovery replication for data durability.
