2. Frontend Codebase Architecture (Views & UI Logic)

📁 frontend/src/app/app.routes.ts Angular Routing & Guards

• Responsibility: Central registry of all client-side application routes (/dashboard, /admin, /qr-scanner, /inventory) with Route Guards (authGuard, adminGuard) to protect restricted endpoints from unauthenticated access.

• Maintenance Target: Modify this file when creating new application pages or enforcing role-based route permissions.

📁 frontend/src/app/qr-scanner/qr-scanner.page.ts Capacitor Camera Scanner

• Responsibility: Orchestrates device camera hardware through Capacitor Barcode Scanner to read optical QR placards on gym machines.

• Maintenance Target: Modify this file to adjust scanner sensitivity, camera focus parameters, or tutorial modal display behavior upon scanning.

📁 frontend/src/app/inventory/inventory.page.ts Shop Cart & POS

• Responsibility: Supplement shop interface where lifters browse products, manage cart quantities, and initiate checkout via Cash or GCash reference verification.

• Maintenance Target: Modify this file to update cart pricing calculations or the GCash transaction reference modal.

📁 frontend/src/app/coaching/chat/chat.page.ts Laravel Echo WebSockets

• Responsibility: Real-time bi-directional messaging interface between coaches and trainees, featuring in-chat workout proposal cards with 1-tap client acceptance.

• Maintenance Target: Modify this file to customize chat bubble layouts, proposal action triggers, or real-time typing indicators.

📁 frontend/src/app/admin/admin.page.ts HTML5-QRCode & Admin POS

• Responsibility: Administrative command terminal housing the optical webcam turnstile scanner, pass renewal interface, and shop order approval dashboard.

• Maintenance Target: Modify this file to adjust webcam barcode frame rates or order approval modals.

📁 frontend/src/app/admin-reports/admin-reports.page.ts jsPDF & AutoTable Engine

• Responsibility: Dedicated reporting center allowing administrators to select date filters and export vector PDF documents and spreadsheets for Attendance, Sales, and Inventory.

• Maintenance Target: Modify this file to adjust tabular report layouts, column headers, or export formatting.

3. Backend Codebase Architecture (Server Business Logic & Database)

📁 backend/routes/api.php REST API Routing Registry

• Responsibility: Registers over 120+ RESTful API endpoints secured by Laravel Sanctum token authentication and custom Role-Based Access Control middleware.

• Maintenance Target: Modify this file when exposing new API resources or adjusting URL path conventions.

📁 backend/app/Http/Controllers/Api/AttendanceController.php Turnstile & Anti-Pass-Sharing

• Responsibility: Ingests optical QR scan payloads, validates pass subscription status, records daily entry logs, and executes anti-pass-sharing timestamp validation.

• Maintenance Target: Modify this file to adjust turnstile anti-pass-sharing lockout durations or attendance query algorithms.

📁 backend/app/Http/Controllers/Api/InventoryController.php ACID Row-Level Locking Checkout

• Responsibility: Executes cart checkout procedures wrapped in ACID database transactions using pessimistic row locking (lockForUpdate()) to guarantee zero negative inventory anomalies.

• Maintenance Target: Modify this file to update order payment verification workflows or warehouse replenishment routines.

📁 backend/app/Http/Controllers/Api/ProposalController.php In-Chat Coaching Proposals

• Responsibility: Governs creation, dispatch, and client acceptance of structured workout training proposals with custom pricing within the chat stream.

• Maintenance Target: Modify this file to adjust training session auto-scheduling or coach fee accounting upon client acceptance.

📁 backend/database/migrations/ 42 MySQL Schema Migrations

• Responsibility: Sequential database migration definitions constructing 21 normalized relational tables, foreign key constraints, column data types, and composite B-tree performance indexes.

• Maintenance Target: Create new migrations here via php artisan make:migration when adding tables or altering database schemas.

4. DevOps, Containers & Deployment Architecture

📁 docker-compose.prod.yml 6-Container Micro-Services

• Responsibility: Orchestration configuration defining 6 production containers: MySQL database, Laravel API backend, Reverb WebSocket engine, background queue worker, Ionic/Angular frontend, and Nginx edge gateway.

• Maintenance Target: Modify this file to adjust network ports, container environment variables, or resource allocation limits.

📁 deploy.sh 1-Click VPS Deploy Script

• Responsibility: Automated continuous deployment bash script that pulls the latest source code from GitHub, compiles container images, runs database migrations, and restarts services safely.

• Maintenance Target: Modify this file when adding build steps or post-deployment cache optimization commands on the live Cloud VPS.
